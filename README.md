# LAKE 영어회화연습

기본 상황극·200일 코스·단어 카드는 AI 연결 없이 사용할 수 있습니다. Gemini AI 상황극은 내 답변을 기억하며 대화를 이어가고, 종료 후 교정 표현을 복습 노트에 저장합니다.

## 실행

Node.js 22 이상이 설치된 PC에서 **Start-English.cmd**를 실행한 뒤 `http://127.0.0.1:4173`을 엽니다. 또는 프로젝트 폴더에서 다음을 실행합니다.

```sh
npm start
```

설치할 npm 패키지는 없습니다. 서버는 이 PC의 127.0.0.1에서만 접근할 수 있습니다. 창을 닫거나 Ctrl+C를 누르면 서버와 메모리에 보관한 키가 함께 종료됩니다. 브라우저 마이크는 지원되는 Chrome/Edge에서 이용하고, 지원되지 않으면 텍스트로 답변합니다. 스마트폰 원격 접속이나 외부 배포는 이 구성에 포함하지 않습니다.

## 비용 0원으로 Gemini 연결하기

1. [Google AI Studio API 키](https://aistudio.google.com/api-keys)에서 **결제가 연결되지 않은 Free Tier 프로젝트**의 키를 만듭니다.
2. 프로젝트의 Billing Tier가 **Free Tier**인지 직접 확인합니다. 결제 계정을 연결하거나 유료 등급으로 전환하지 않습니다.
3. 앱의 **상황극 → Gemini 무료 연결 설정**을 열고 키를 입력한 뒤 무료 프로젝트 확인란을 체크합니다.
4. **무료 프로젝트로 연결 → Gemini AI 대화 → 상황 선택** 순서로 시작합니다.

**API 키만으로 앱이 결제 상태를 검증할 수는 없습니다. 유료 프로젝트 키를 넣으면 Google에서 요금이 발생할 수 있습니다. 비용 0원은 결제가 연결되지 않은 무료 프로젝트를 사용하는 것이 전제입니다.** 앱에는 결제 연결 기능, 유료 모델 전환, 자동 재시도가 없습니다.

고정 모델은 `gemini-2.5-flash-lite`입니다. [공식 요금표](https://ai.google.dev/gemini-api/docs/pricing)에서 무료 입력·출력 등급을 확인했습니다(2026-09-03). 모델 이용 가능 여부와 무료 사용량은 계정·지역·Google 정책에 따라 달라질 수 있습니다. 모델이 제공되지 않으면 자동 대체하지 않고 연결 오류를 표시합니다. [결제 등급 안내](https://ai.google.dev/gemini-api/docs/billing)

무료 한도 오류(429)를 받으면 이후 AI 요청을 차단합니다. 한도가 회복된 후에만 설정에서 키를 다시 입력해 연결하세요. 서버 재시작·재연결은 Google의 한도를 초기화하지 않습니다. 기존 기본 상황극은 계속 사용할 수 있습니다. 별도 호스팅을 사용하지 않아 호스팅 요금이 없으며, 인터넷·PC 사용 비용은 별도입니다.

## 대화와 복습

- 초급/중급 선택, 최대 6번의 학습자 답변. 대화 도중에는 정답 판정으로 끊지 않습니다.
- 음성 입력 또는 텍스트 전송 → Gemini의 문맥 기반 답변 → 브라우저 읽어주기.
- **답변 후 자동으로 듣기**는 사용자가 켰을 때만 동작합니다. 자동 듣기가 멈추면 다시 눌러 말하거나 입력합니다.
- 한국어 해석·예문 힌트는 필요할 때 펼칩니다. 다시 듣기·천천히 듣기를 제공합니다.
- 대화 종료 후 실제로 말한 문장에 근거한 최대 3개 교정과 다음 연습 표현을 제공합니다. 음성인식 결과로 발음 점수를 만들지 않습니다.
- 복습 후 **이 표현으로 다시 대화하기**를 선택해 같은 상황에서 다시 사용합니다.
- 복습 노트는 이 브라우저에 최근 20회만 저장됩니다. 전체 대화·API 키는 브라우저 저장소에 저장하지 않습니다. 복습 노트에는 내 문장 일부가 남습니다. **기록 지우기**로 삭제할 수 있습니다.
- 3회 이상 답변하고 복습까지 마친 대화에 8 XP를 한 번 지급합니다. 기존 기본 상황극의 보상과 구분됩니다.

## 개인정보와 연결

키는 이 PC의 서버 메모리에만 보관하며 상태 응답·로그·브라우저 저장소·파일에 반환하거나 저장하지 않습니다. 설정 폼에서 이 로컬 서버로 키를 전달하고, 대화 요청은 서버가 Google Gemini API로 보냅니다. 무료 등급 입력·출력은 Google 제품 개선에 사용될 수 있으므로 실제 예약번호·여권번호 등 개인정보를 넣지 마세요.

이 구현은 **브라우저 음성인식 + 텍스트 기반 Gemini API + 브라우저 음성합성**입니다. 통화형 원음 스트리밍이나 Gemini Live API 구현은 아닙니다. 음성 품질과 인식 지원은 브라우저/운영체제에 따라 달라집니다. 영어 음성은 홈의 음성 설정에서 고를 수 있습니다.

## 검증

```sh
npm test
```

Node 내장 테스트로 요청 경계, 무료 확인 전 호출 차단, 한도 차단, 대화 맥락, 취소/중복 전송과 저장을 검증합니다. 테스트 응답을 주입하므로 외부 API를 호출하지 않습니다. 실제 Gemini 품질과 마이크 인식은 무료 키와 해당 기기에서 확인해야 합니다.
